# Legacy Spartan references

The `backend-micronaut/` and `database/` directories are preserved from the original Spartan installation for historical reference only. They describe Kotlin, Micronaut, Gradle, Exposed, and Flyway projects and do not apply automatically to JoapyCore's `BACK/` NestJS/Prisma code.

Current project rules live under `.claude/rules/backend-nestjs/`, `.claude/rules/shared-backend/`, and `.claude/rules/frontend-react/`.
